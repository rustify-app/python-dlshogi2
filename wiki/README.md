# Wiki の編集と公開

公開する Markdown ページの原稿はこのフォルダーにあります。ページを編集したら、変更を確認してから次のコマンドで GitHub Wiki に反映します。

    ./wiki/publish.sh --dry-run
    ./wiki/publish.sh

公開時はこのフォルダー内の Markdown を Wiki に同期します。ブラウザー上で直接編集した内容は、次回の同期で上書きされます。

## 執筆ルール

- 日本語で簡潔に書き、事実ごとに掲載先を一つにします。
- Wiki ページ同士をリンクしません。
- 現在の状況と必要な操作を、表・箇条書き・図でまとめます。
- 変更履歴、日常的な問題、不要な警告、コードから確認できる説明は載せません。
- 不安定な情報や特定の端末に依存する情報は載せません。
