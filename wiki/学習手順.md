# 学習手順

## 棋譜の変換

CSA 棋譜を HCPE 形式に変換し、学習用と評価用のデータを作ります。

    python utils/csa_to_hcpe.py csa_dir train.hcpe test.hcpe --filter_moves 50 --filter_rating 3500 --test_ratio 0.1

分割は棋譜単位で行います。同じ対局の局面が学習用と評価用の両方に入ることを防ぎます。

## 価値の教師信号

対局結果だけでなく、棋譜に記録された評価値から換算した勝率も使います。--val_lambda は対局結果の重みです。既定値は 0.333、評価値を勝率へ換算する係数 --eval_coef は 600 です。

## 学習と再開

    python -m pydlshogi2.train train.hcpe test.hcpe --gpu 0 --epoch 10 --batchsize 1024 --lr 0.01 --save_interval 1000 --checkpoint checkpoints/latest.pth --metrics metrics/train.jsonl

中断後は同じチェックポイントを指定して再開します。

    python -m pydlshogi2.train train.hcpe test.hcpe --gpu 0 --epoch 10 --resume checkpoints/latest.pth --checkpoint checkpoints/latest.pth --metrics metrics/train.jsonl

--save_interval を指定すると一定間隔で保存します。--resume 時の --epoch は再開後に追加するエポック数です。ネットワーク構成はチェックポイントから復元されます。

## 複数候補手を使う学習

USI 対応エンジンで各局面を解析し、候補手と評価値から作った方策教師データを保存します。教師データと同じ局面だけを HCPE に書き出すため、出力された HCPE を学習・評価に使います。

    python utils/make_multipv_targets.py train.hcpe train-targets.npz --engine /path/to/YaneuraOu --engine-dir /path/to/engine --multipv 5 --nodes 512 --max-positions 10000 --positions-output train-sample.hcpe
    python utils/make_multipv_targets.py test.hcpe test-targets.npz --engine /path/to/YaneuraOu --engine-dir /path/to/engine --multipv 5 --nodes 512 --max-positions 2000 --positions-output test-sample.hcpe
    python -m pydlshogi2.train train-sample.hcpe test-sample.hcpe --gpu 0 --epoch 10 --batchsize 1024 --teacher_targets train-targets.npz --teacher_targets_test test-targets.npz --resume checkpoints/latest.pth --checkpoint checkpoints/multipv-{epoch:03}.pth

--max-positions で解析する局面数を制限します。教師データにない局面は HCPE に記録された最善手を使います。

## 自己対局データの重複と世代

複数の自己対局ファイルを古い世代から新しい世代の順に渡します。`--deduplicate_positions` は同じ局面の最も新しいレコードを残し、`--recency_decay` は1世代古くなるごとの局面抽出重みを指定します。0.5なら一世代ごとに半分です。

    python -m pydlshogi2.train rl/selfplay-*.hcpe test.hcpe --gpu 0 --epoch 10 --batchsize 1024 --deduplicate_positions --recency_decay 0.5 --resume checkpoints/latest.pth --checkpoint checkpoints/recent-{epoch:03}.pth

重複削除後の固有局面数を各エポックの抽出数に使います。減衰を有効にした場合は重みに従って復元抽出します。
