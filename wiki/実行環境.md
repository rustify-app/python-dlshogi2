# 実行環境

| 用途 | 必要な環境 |
|---|---|
| 学習 | Python と PyTorch。GPU を使う場合は対応する CUDA 環境 |
| 自己対局・USI エンジン | Python と cshogi。推論に応じて PyTorch または ONNX Runtime |
| 計測ダッシュボード | Python とダッシュボード用依存パッケージ。GPU は不要 |

CPU でもエンジンを動かせますが、学習や多数の自己対局には GPU が適しています。各用途の依存関係と導入コマンドはリポジトリの README と requirements.txt にまとめています。
