# 将棋エンジン

エンジンは USI に対応し、USI 対応の将棋 GUI から利用できます。GUI には Python モジュールではなく起動用スクリプトを登録します。

| 実行方式 | 起動スクリプト | モデル |
|---|---|---|
| PyTorch | scripts/mcts_player.sh または scripts/mcts_player.bat | 学習チェックポイント .pth |
| ONNX Runtime | scripts/onnx_player.sh または scripts/onnx_player.bat | このプロジェクトで出力した .onnx |

ONNX モデルの出力例:

    python utils/export_onnx.py checkpoints/checkpoint.pth model/model.onnx

GUI のエンジン設定では modelfile にモデルの場所を指定します。GPU を使わない場合は gpu_id を -1 にします。探索や持ち時間の設定値は GUI から変更できます。
