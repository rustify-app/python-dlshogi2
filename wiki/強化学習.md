# 強化学習

強化学習ループは、自己対局、追加学習、候補モデルの対局評価を繰り返します。開始時には教師あり学習済みチェックポイントを指定します。

    ./scripts/rl_loop.sh checkpoints/checkpoint.pth

## 反復の流れ

1. 現在のモデルで自己対局し、棋譜データを作成します。
2. 作成したデータで追加学習し、候補モデルを保存します。
3. 現行モデルと候補モデルを同じ序盤・探索回数で対局させ、SPRTで比較します。各序盤は先後を入れ替えて対局します。
4. SPRTが候補の採用を認めた場合だけ候補を次の反復に使います。棄却または判定保留なら現行モデルを維持します。比較結果が欠落・不正の場合は処理を失敗させ、昇格しません。

## 主な環境変数

| 変数 | 既定値 | 内容 |
|---|---:|---|
| ITERATIONS | 20 | 反復回数 |
| GAMES | 1000 | 反復ごとの自己対局数 |
| PLAYOUTS | 400 | 自己対局での1手あたり探索回数 |
| WORKERS | 8 | 並列自己対局プロセス数 |
| EPOCHS | 1 | 反復ごとの追加学習回数 |
| BATCHSIZE | 1024 | 学習バッチ数 |
| LR | 0.002 | 学習率 |
| VAL_LAMBDA | 0.5 | 対局結果を使う価値教師信号の重み |
| GPU | 0 | 使用するGPU番号 |
| WORKDIR | rl | 生成物の保存先 |
| PROMOTION_ENABLED | 1 | 対局による昇格判定を有効化。0の場合は候補を自動採用 |
| PROMOTION_GAMES | 100 | 候補評価の対局数。偶数を指定 |
| PROMOTION_PLAYOUTS | PLAYOUTSの値 | 候補評価での1手あたり探索回数 |
| PROMOTION_ELO0 | 0 | SPRTの帰無仮説のElo差 |
| PROMOTION_ELO1 | 5 | SPRTの対立仮説のElo差 |
| PROMOTION_ALPHA | 0.05 | 第一種過誤率 |
| PROMOTION_BETA | 0.05 | 第二種過誤率 |
| PROMOTION_PLIES | 12 | 序盤生成で進める手数 |
| PROMOTION_TOP_K | 8 | 序盤生成で選択対象とする候補手数 |

既存の自己対局データと候補チェックポイントは再実行時に再利用されます。不完全な生成ファイルは再利用前に削除してください。
