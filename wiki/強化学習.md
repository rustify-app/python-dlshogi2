# 強化学習

強化学習ループは、自己対局、自己対局データによる追加学習、次の反復へのモデル更新を繰り返します。開始時には教師あり学習済みチェックポイントを指定します。

    ./scripts/rl_loop.sh checkpoints/checkpoint.pth

## 反復の流れ

1. 現在のモデルで自己対局し、HCPE データを作成します。
2. 作成済みの自己対局データ全体を使って追加学習します。
3. 新しいチェックポイントを次の反復のモデルにします。

現行ループは学習後のモデルを自動で次へ進めます。対局による強さの確認を昇格条件にはしていません。評価用に渡す最新の自己対局データは学習にも使うため、学習指標は性能比較ではなく発散確認として扱います。

## 主な環境変数

| 変数 | 既定値 | 内容 |
|---|---:|---|
| ITERATIONS | 20 | 反復回数 |
| GAMES | 1000 | 反復ごとの対局数 |
| PLAYOUTS | 400 | 1 手あたりの探索回数 |
| WORKERS | 8 | 並列自己対局プロセス数 |
| EPOCHS | 1 | 反復ごとの追加学習エポック数 |
| BATCHSIZE | 1024 | 学習バッチ数 |
| LR | 0.002 | 学習率 |
| VAL_LAMBDA | 0.5 | 対局結果を使う価値教師信号の重み |
| GPU | 0 | 使用する GPU 番号 |
| WORKDIR | rl | 生成物の保存先 |

既存の自己対局ファイルとチェックポイントは再実行時に再利用されます。中断中に書き込まれた不完全なファイルは、再利用前に削除してください。
