# 探索

エンジンは方策ネットワークの着手確率を事前情報として使い、PUCT によるモンテカルロ木探索を行います。葉局面をまとめてネットワークへ渡すことで GPU 推論を効率化します。

## 探索の要点

- 合法手だけを探索対象にします。
- 訪問回数と評価値を方策確率と組み合わせ、次に読む手を選びます。
- 同時に進む探索が同じ葉へ集中しないよう、評価完了まで仮想損失を加えます。
- 既に探索した局面へ進んだ場合は、利用可能な探索木を再利用します。
- 詰み、入玉、千日手は探索評価とは別に処理します。

## 調整できる主な USI 設定

| 設定 | 既定値 | 用途 |
|---|---:|---|
| batchsize | 32 | 一度に評価する局面数。大きくすると推論効率が上がる一方、評価待ちの局面が増えます |
| c_puct | 100（1.00） | 方策に基づく探索の強さ。小数値を 100 倍した整数で指定します |
| fpu_reduction | 27（0.27） | 未探索の手に与える初期評価の減衰率 |
| temperature | 100（1.00） | 方策確率の平滑化。小数値を 100 倍した整数で指定します |
| mate_root_ply | 7 | 探索開始時に行う詰み探索の深さ |
| resign_threshold | 1（1%） | 投了する勝率のしきい値。0 で投了しません |
| time_margin | 1000 ミリ秒 | 通常持ち時間の安全余裕 |
| byoyomi_margin | 100 ミリ秒 | 秒読みの安全余裕 |
| pv_interval | 500 ミリ秒 | 読み筋を出力する間隔。0 で出力しません |

固定プレイアウト数は探索量をそろえた比較に、固定時間は実戦での強さと速度を含めた比較に使います。
