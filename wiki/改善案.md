## やねうら王を目標にした取り組み（2026-10-24〜）

目標はやねうら王 NNUE 9.00beta1（HalfKP 512x2-8-64）に勝つことです。同じ持ち時間での差は当初約1200 Eloと見積もっていました。上の表の改善案は1000局で検出できない大きさだったため、効果の大きい順に次を進めています。

| 取り組み | 結果 |
|---|---|
| やねうら王による教師データ生成（`utils/gen_teacher.py`、1局面1万ノード） | Vast.ai の CPU 機で毎秒約4000局面。重複0.06%、勝敗は先手52%・後手47%・引き分け1% |
| 評価値教師の符号バグ修正 | 後手番の局面で評価値の勝率を反転していた（2026-06から）。val_lambda<1 の学習すべてに影響。修正後、3000ステップ時点の価値正解率が49.5%から72.6%に上昇 |
| 教師データ2237万局面で10×192を1エポック（修正前のコード） | checkpoint-005 に155勝0敗（800プレイアウト、打ち切り）。やねうら王に対し1000ノードで90勝10敗、5000ノードで30勝69敗1分、2万ノードで2勝96敗2分 |
| ふかうら王（YaneuraOu の dlshogi 互換エンジン、TensorRT）への移行 | `--features dlshogi` で学習し `utils/export_dlshogi_onnx.py` で書き出す。RTX 3090 で10×192が毎秒約6.6万ノード（Python版 MCTS は毎秒4336） |
| 教師データ1984万局面・dlshogi特徴量・10×192を1エポック（r1） | 方策一致率46.3%、価値正解率75.9%。ふかうら王（RTX 3090）対やねうら王（1スレッド）、1手1秒で2勝21敗2分（打ち切り）。同じ持ち時間でまだ約350 Elo差 |
| 教師データ3391万局面・dlshogi特徴量・10×192を2エポック（r2） | 方策一致率49.7%、価値正解率78.0%。ふかうら王（RTX 3090）対やねうら王（1スレッド）、1手1秒で3勝19敗2分（打ち切り）。r1と有意差なし。Rustify本番の rl-020 に対し、400プレイアウトで24勝2敗4分（推定+325 Elo）、CPUでの速度は同等（5秒で約400ノード） |
| 教師データ7111万局面・dlshogi特徴量・20×256（SEあり）を2エポック（r3） | RTX 3090で約13時間。方策一致率53.2%、価値正解率79.4%。ふかうら王（RTX 2060、毎秒約8000ノード）対やねうら王（1スレッド）、1手1秒で8勝19敗3分、推定−134±130 Elo。ネットワーク拡大で約200 Elo縮まった |

ふかうら王とやねうら王を秒読みで対局させるときは、両方の `NetworkDelay` と `NetworkDelay2` を0にし、ふかうら王の `RoundUpToFullSecond` を false にします。既定値のままでは1秒未満の秒読みでほとんど考えずに指します。

## floodgate 4000 を目標にした取り組み（2026-11-02〜）

rustify_dl（r3、ふかうら王、RTX 2060）は floodgate で 3500（112勝138敗）。3300以下にはほぼ全勝、3580前後と互角、3650以上には 0勝60敗超。

負けた対局を見ると、評価値は 100手前後まで互角か有利で、そこから崩れていた。原因は持ち時間の使い方：定跡なし（`BookFile=no_book`）のため、序盤の自分の 15手に 230〜340秒を使っていた。持ち時間 300秒をほぼ使い切り、中盤以降は加算の 10秒だけで指していた。さらに csa_client が先読み（ponder）に対応しておらず、相手の手番の時間を使っていなかった。

| 取り組み | 状況 |
|---|---|
| 定跡: やねうら王の新ペタショック定跡（233万局面、MIT）。`BookEvalDiff=20` で手を散らす | 2026-11-02 投入。floodgate.yaml の init が初回だけ取得する |
| ponder: `csa_client --ponder`（go ponder / ponderhit / stop） | 2026-11-02 投入 |
| 定跡・ponder 投入後の8局 | 2勝5敗1分（相手は主に4000前後）、レート3476。序盤30手で使う時間は230〜340秒から約150秒に減った（定跡を早く外れた局は273秒）。負けは118〜147手目で崩れる |
| 時間配分: `SlowMover` 100→85 | 2026-11-02 投入。定跡を早く外れた局で100手目に残り12秒まで減っていた。逆に残り96〜157秒を余らせて負けた局もあるので、数日分の結果で見直す |
| r4: floodgate 2019〜2026 の両者3500以上（3130万局面）で r3 から1エポック追加学習（Vast.ai RTX 3090、約8時間） | **不採用**。test 正解率は policy 0.533 / value 0.743 と上がったが、r3 との対局（800プレイアウト）では 20勝44敗6分、Elo -124±81 で SPRT により棄却された（ログと棋譜: model/r4/）。人間・他ソフトの棋譜に lr 0.02 で寄せたことで、自己対局で育った r3 の強さが崩れたとみられる。次に試すなら lr をもっと小さくする（0.002 程度）か、r3 自身の自己対局データを混ぜる |
| GPU: 2060（中盤で毎秒約 5400ノード、2026-11-03）。同じ GPU 帯の公開 DL エンジンは 3070 で 4008、3080 で 4030 | 差の主因はモデル（研究資料 3 章）。NPS は #4 で測る |
