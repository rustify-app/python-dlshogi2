# 計測記録

学習、自己対局、強化学習ループ、エンジン対局は、実行条件と結果を JSONL 形式で記録できます。学習・自己対局・対局では --metrics に保存先を指定します。強化学習ループは WORKDIR/metrics に記録します。

## 記録の使い方

- 1 回の実行につき 1 ファイルを使います。
- 同じ実行を再開して一つの記録にまとめる場合は、同じ --run_id を指定します。
- 対局結果を比較するときは、モデル名と対局条件をそろえて記録を残します。
- JSONL は 1 行 1 件の JSON です。標準的な JSON ツールで読み取れます。

## 実行例

    python -m pydlshogi2.train train.hcpe test.hcpe --metrics metrics/train.jsonl
    python -m pydlshogi2.selfplay checkpoints/checkpoint.pth selfplay.hcpe --metrics metrics/selfplay.jsonl
    python -m pydlshogi2.match --engine1 ./scripts/usi_engine.sh --engine2 ../baseline/scripts/usi_engine.sh --metrics metrics/match.jsonl
